## Ordering

Discover groups coding harnesses before meta harnesses, then uses a stable editorial popularity order within each group. It does not claim measured usage or live rankings. Public GitHub interest informs open-source placement; established product visibility informs closed-source placement. Installation state does not move a tool ahead of its group.

Reference snapshots: https://github.com/stablyai/orca (72.1k stars), https://github.com/pingdotgg/t3code (23.1k), https://github.com/getpaseo/paseo (17.7k). Stars are signals, not user counts or a comparable measure for closed-source tools.
